# Reflection

In this laboratory activity, I learned how to use a cloud-based Linux environment through KillerCoda. At first, I was not very familiar with using the terminal, but the activity helped me understand how basic Linux commands work.

I learned how to check system information such as the Linux distribution, kernel version, CPU information, memory, and disk space. I also learned how to create folders and Markdown files using Linux commands.

Using GitHub also helped me understand how files and documentation can be organized in one repository. I learned that proper documentation is important because it makes the activities and information easier to understand and review.

Overall, this laboratory activity gave me more experience in using Linux, Markdown, and GitHub. It also helped me become more familiar with the basic tools that are used in cloud computing.
