# Laboratory 01 - Welcome to the Cloud

## Mission Overview

This laboratory activity introduced me to a cloud-based Linux environment using KillerCoda. I learned how to use basic Linux commands, gather system information, organize files and directories, and document my work using Markdown and GitHub.

## Objectives

- Access and explore a Linux environment using KillerCoda.
- Learn basic Linux commands.
- Gather system information from the Linux environment.
- Create and organize files and directories.
- Use Markdown for documentation.
- Maintain a Cloud Computing Portfolio using GitHub.

## Activities Performed

- Accessed the KillerCoda Linux Playground.
- Created and logged in to my Linux user account.
- Checked the current username, working directory, and hostname.
- Gathered Linux system information.
- Created Documents, Notes, Reports, and Screenshots directories.
- Created an about-me.md file.
- Created and organized my GitHub Cloud Computing Portfolio.

## Linux Commands Used

- `whoami`
- `pwd`
- `hostname`
- `cat /etc/os-release`
- `uname -r`
- `lscpu`
- `free -h`
- `df -h`
- `cd`
- `mkdir`
- `ls`
- `nano`
- `cat`

## Skills Learned

I learned how to navigate a Linux environment, execute basic Linux commands, gather system information, create files and directories, use Markdown, and organize my work using GitHub.
