# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides services that organizations can use to host applications, store data, manage computing resources, and support different IT workloads in the cloud.

## Global Infrastructure

Azure operates cloud infrastructure across many geographic locations. Its regions allow organizations to deploy resources closer to users and choose suitable locations for their applications and data.

## Cloud Management Console

The Azure portal is the web-based management interface for Azure. It allows users to create, configure, monitor, and manage cloud resources from one place.

## Four Core Services

### Azure Virtual Machines

Azure Virtual Machines provides virtualized computing resources that can run Windows or Linux operating systems.

### Azure Blob Storage

Azure Blob Storage provides object storage for files and unstructured data such as documents, images, videos, backups, and application files.

### Azure Virtual Network

Azure Virtual Network allows cloud resources to communicate through a private virtual network. It can also help connect Azure resources with existing organizational networks.

### Microsoft Entra ID

Microsoft Entra ID is used for identity and access management. It helps organizations manage users, authentication, and access to applications and cloud resources.

## Three Advantages

- Azure works closely with Microsoft products and technologies.
- It supports both cloud-only and hybrid computing environments.
- Organizations can deploy resources across different geographic regions.

## Typical Enterprise Use Cases

Azure can be used for migrating existing systems to the cloud, running virtual machines, storing data, managing identities, hosting applications, and supporting organizations that already use Microsoft technologies.
