## KillerCoda Linux Server Investigation

For this checkpoint, I used the KillerCoda Linux environment to examine the operating system, CPU, memory, and disk space of the server.

### Operating System

- **Operating System:** Ubuntu 24.04.4 LTS
- **Architecture:** x86_64

### CPU Information

- **Processor:** Intel Xeon E312xx (Sandy Bridge, IBRS update)
- **CPU(s):** 1

### Memory

- **Total Memory:** 1.9 GiB
- **Used Memory:** 416 MiB
- **Available Memory:** 1.5 GiB
- **Swap:** 1.0 GiB

### Disk Space

- **Main Filesystem:** /dev/vda1
- **Total Size:** 19 GB
- **Used:** 5.4 GB
- **Available:** 13 GB
- **Usage:** 30%

## Cloud Migration

If this Linux server were migrated to the cloud, it could be hosted using the following services:

- **AWS:** Amazon EC2
- **Microsoft Azure:** Azure Virtual Machines
- **Google Cloud:** Compute Engine

These three services provide virtual machines that can be used to run Linux-based servers in their respective cloud platforms.
