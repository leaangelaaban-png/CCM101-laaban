| Launch Year | 2006 | 2010 | 2008 |
| Compute Service | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage Service | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking Service | Amazon VPC | Azure Virtual Network | Google Cloud VPC |
| Identity Service | AWS IAM | Microsoft Entra ID | Cloud IAM |
| Primary Strength | Wide range of cloud services | Microsoft integration and hybrid cloud | AI, data, and Kubernetes |
| Ideal Organizations | Organizations needing flexible and broad cloud services | Organizations already using Microsoft systems | Organizations focused on AI, analytics, and containers |

# Comparison Questions

## 1. Which provider offers the broadest range of cloud services?

AWS offers a broad selection of cloud services that cover computing, storage, networking, databases, security, analytics, and many other areas.

## 2. Which provider integrates best with Microsoft environments?

Microsoft Azure is the strongest choice for Microsoft environments because it is designed to work closely with Microsoft technologies and services.

## 3. Which provider is strongest in AI and Kubernetes technologies?

Google Cloud is a strong choice for AI and Kubernetes workloads because it provides specialized AI services and Google Kubernetes Engine.

## 4. Which cloud provider would you personally choose and why?

I would personally choose Microsoft Azure because I am interested in how cloud services can work together with technologies that many organizations already use. Azure stands out to me because it supports both cloud resources and existing Microsoft environments. I would like to explore how organizations can gradually move their systems to the cloud without completely changing the technologies they already depend on.
