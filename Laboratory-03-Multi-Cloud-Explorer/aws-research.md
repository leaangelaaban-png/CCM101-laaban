# Amazon Web Services (AWS) Research

## Brief Overview

Amazon Web Services (AWS) is a cloud platform that provides computing resources and other technology services through the internet. Organizations can use AWS services without having to build and maintain all of their own physical infrastructure.

## Global Infrastructure

AWS has a global infrastructure composed of Regions and Availability Zones. These locations allow organizations to place applications and resources in different parts of the world depending on their availability, performance, and business requirements.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. It allows users to configure resources, monitor services, and manage different parts of their cloud environment.

## Four Core Services

### Amazon EC2

Amazon EC2 provides virtual machines in the cloud. It can be used to host applications, websites, servers, and other computing workloads.

### Amazon S3

Amazon S3 is an object storage service used to store files and data such as documents, backups, media, and application content.

### Amazon VPC

Amazon VPC provides a virtual network where AWS resources can be placed and connected. It gives users control over networking settings such as subnets, IP addresses, and routing.

### AWS IAM

AWS Identity and Access Management helps control who can access AWS resources and what actions they are allowed to perform.

## Three Advantages

- AWS offers many services for different types of cloud workloads.
- Its global infrastructure can support organizations with users in different locations.
- Resources can be increased or reduced depending on the demand of an application.

## Typical Enterprise Use Cases

AWS can be used for application hosting, cloud storage, backup, databases, enterprise systems, websites, and scalable online services.
