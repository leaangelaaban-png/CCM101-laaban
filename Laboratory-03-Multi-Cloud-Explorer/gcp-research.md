# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud is a cloud computing platform that provides computing, storage, networking, data, artificial intelligence, and other cloud services. Organizations can use these services to build and operate applications without relying only on their own physical infrastructure.

## Global Infrastructure

Google Cloud uses regions and zones to organize its global cloud infrastructure. These locations allow organizations to deploy resources according to performance, availability, and geographic requirements.

## Cloud Management Console

The Google Cloud console is a web-based interface used to access, configure, and monitor Google Cloud resources and projects.

## Four Core Services

### Compute Engine

Compute Engine provides virtual machines that can run applications and other computing workloads on Google Cloud infrastructure.

### Cloud Storage

Cloud Storage provides object storage for files, backups, media, and application data.

### Virtual Private Cloud

Google Cloud VPC provides networking for cloud resources and allows organizations to manage how those resources communicate.

### Cloud IAM

Cloud IAM provides access control for Google Cloud resources by using roles and permissions.

## Three Advantages

- Google Cloud provides strong tools for data and AI-related workloads.
- It supports scalable cloud applications across different regions.
- Google Kubernetes Engine provides managed Kubernetes services for containerized applications.

## Typical Enterprise Use Cases

Google Cloud can be used for data analytics, artificial intelligence, application hosting, cloud storage, virtual machines, and containerized workloads.
