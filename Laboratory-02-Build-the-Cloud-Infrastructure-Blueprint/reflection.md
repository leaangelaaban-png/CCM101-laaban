# Mission Reflection

## What did you learn from investigating the Linux environment?

I learned that Linux provides useful commands for examining the resources and configuration of a server. Through the investigation, I was able to identify information about the operating system, processor, memory, disk capacity, mounted file systems, hostname, and IP address. Reading these results helped me understand what information administrators can examine when working with a Linux server.

## How do compute, storage, and networking resources work together?

Compute resources are responsible for processing instructions and workloads, while storage resources keep the files and data needed by the system. Networking resources provide communication between the server, users, and other systems. These components depend on one another to provide a functional cloud environment.

## What did you learn from comparing AWS, Azure, and Google Cloud Platform?

I learned that the three major cloud providers offer services for many of the same infrastructure needs. AWS, Azure, and Google Cloud Platform all provide compute, storage, networking, and identity and access management services, but each provider has its own service names and ecosystem.

## Which cloud infrastructure component do you think is the most important and why?

I consider compute resources very important because they provide the processing capability required to run applications and workloads. Without enough computing resources, a server may not be able to process the tasks required by its users and services efficiently.

## How can you apply what you learned to real-world cloud systems?

The knowledge from this laboratory can help me examine basic server information and recognize the resources used in a cloud environment. Understanding Linux commands can also help when troubleshooting or checking the condition of a server. These skills provide a useful starting point for working with more advanced cloud technologies in the future.
