# Laboratory Activity 5 - The Cloud Data Engineer

## Mission Overview

This activity introduced me to cloud object storage using MinIO and Docker. I compared different storage types and applied what I learned by creating a working object storage environment. I deployed MinIO, accessed its web console, created a bucket, and uploaded a sample file.

## Objectives

- Compare Block, File, and Object Storage.
- Understand the purpose of each storage type.
- Deploy MinIO using a Docker container.
- Access the MinIO web console through a mapped port.
- Create an object storage bucket.
- Upload a file into the bucket.
- Document the completed activity using Markdown and GitHub.

## Tools Used

- KillerCoda Ubuntu Playground
- Docker
- MinIO
- Git
- GitHub
- Web Browser
- Markdown

## Skills Learned

I learned how Object Storage can be used in an actual cloud environment instead of only understanding it through definitions. I practiced deploying MinIO with Docker, checking if a container was running, using port mapping, and accessing a service through a browser. Creating a bucket and uploading a file also helped me understand how objects are stored and organized.
