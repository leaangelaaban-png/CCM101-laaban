# Automation Research

## 1. Bash Script

A Bash script is a text file containing Linux shell commands that can be executed together to automate a task. The `#!/bin/bash` line, called the shebang, tells the system to use Bash to interpret the script.

## 2. Variables

Variables store values such as folder paths or filenames so they can be reused in a script. For example, `$BACKUP_DIR` lets a script refer to a backup folder without repeatedly typing its full path.

## 3. Cron Job

A cron job is a scheduled task managed by the Linux cron service. It is useful in cloud operations because it can run routine tasks, such as backups, automatically at specified times.
