# Laboratory 06 - Cloud Deployment Engineer

## Mission Overview

This laboratory demonstrated how a multi-tier cloud application can be deployed using Docker Compose. The project used Nextcloud as the application service and MariaDB as the database service, allowing both components to operate together as one cloud application.

## Objectives

- Understand how application and database tiers work together.
- Prepare a Docker Compose configuration.
- Deploy Nextcloud and MariaDB using containers.
- Access the Nextcloud setup interface through a mapped port.
- Practice starting and stopping a multi-container deployment.

## Commands Executed

docker-compose up -d

docker-compose ps

docker-compose down

## Skills Learned

I learned how to create and use a Docker Compose configuration for multiple services. I also practiced checking container status, accessing a service through a port, and managing the application lifecycle using Docker Compose commands.
